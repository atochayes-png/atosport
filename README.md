# ATOSPORT - SaaS de Gestión Deportiva

Plataforma integral de alto rendimiento para organizadores de ligas, torneos, directores deportivos y comisiones arbitrales.

## ⚡ Stack Tecnológico
- **Frontend Core:** React 19 + TypeScript
- **Bundler & Build Tool:** Vite
- **Estilos & Diseño:** Tailwind CSS (Sistema *Dark Sport Professional*)
- **Iconografía:** Lucide React
- **Runtime & Package Manager:** Bun / Node

## 🎨 Sistema de Diseño (Dark Sport Professional)
- **Fondo Principal:** `#070A0F`
- **Contenedores y Tarjetas:** `#0B0F17`
- **Bordes:** `#1E293B` (`border-slate-800`)
- **Textos:** `#E2E8F0` y `#94A3B8`
- **Acentos de Acción:** `#10B981` / `#059669` (Verde Esmeralda Deportivo)

## 🚀 Despliegue en Vercel
Este proyecto está optimizado para compilar directamente en Vercel con cero configuración requerida:
- **Build Command:** `bun run build` o `npm run build`
- **Output Directory:** `dist`
- **Install Command:** `bun install` o `npm install`
